    ¿Cómo funciona la votación?

    Se eligen 350 diputados. Cada provincia reparte un número de asientos según su población, Madrid 38 y Soria 2, por ejemplo. Dentro de cada provincia los asientos se reparten entre los partidos que pasan del 3 % con la ley D'Hondt, un método que favorece un poco a los partidos grandes, sobre todo en las provincias pequeñas. Para gobernar sin apoyos hacen falta 176.

    Los colegios abren de 9:00 a 20:00. El recuento es rápido, hacia las 22:30 suele estar casi todo escrutado.

    Cómo funciona esta app

    Cada hora se descargan las encuestas y las noticias. Se calcula la media de encuestas y, con ella, cómo quedaría cada provincia según el voto de 2023 y la ley D'Hondt. Después se repite ese cálculo 10.000 veces metiendo el error que las encuestas tuvieron en 2019 y 2023, y se cuenta cuántas veces pasa cada cosa. El código está en GitHub.
